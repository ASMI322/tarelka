# Тарелка

Мобильное веб-приложение (PWA) для питания: свайпаете продукты, указываете пол, возраст, рост, вес и цель — приложение считает норму калорий и БЖУ и собирает меню на неделю из блюд с любимыми продуктами. Любое блюдо можно заменить свайпом влево.

## Файлы

- `tarelka.html` — исходник приложения (весь интерфейс, данные и логика).
- `build.ps1` — собирает из него `index.html` для PWA: `powershell -ExecutionPolicy Bypass -File build.ps1`.
- `index.html`, `manifest.webmanifest`, `sw.js`, `*.png` — то, что публикуется на GitHub Pages.

## Установка на iPhone

Откройте адрес GitHub Pages в Safari → «Поделиться» → «На экран „Домой“».

Норма калорий считается по формуле Миффлина — Сан Жеора. Это ориентир, а не медицинская рекомендация.
